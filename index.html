Retrieval pattern

Find the right source before asking the model.

A confident answer can still be wrong if the model starts from the wrong source. I treat source selection and answer generation as two different problems instead of hiding both inside one prompt.

Transferable enterprise-AI design principle
Weak pattern
Large knowledge set→Model answers directly→Plausible wrong context
Separate the problems
Stronger pattern

Operating boundary

AI can explain. Verification needs evidence.

If an AI cannot inspect the authoritative system state, it should not pretend it verified the outcome. It can organise the context, explain what should be checked and point to the evidence. The final verification stays with the person or system that can actually see the state.
